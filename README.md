# 📊 Student Performance Analysis with Python

## 📌 Project Overview

This project explores student performance data using Python. The objective is to understand the dataset, clean and prepare the data, perform exploratory data analysis (EDA), and create visualizations to identify useful patterns.

## 🎯 Objectives

- Explore the structure and characteristics of the dataset.
- Identify missing values and duplicate records.
- Calculate descriptive statistics.
- Analyze the distribution of final grades.
- Explore relationships between study time, absences, and academic performance.
- Communicate findings through data visualizations.

## 📂 Dataset

The project uses the **Student Performance Dataset** from the UCI Machine Learning Repository.

The dataset contains information about students, including study time, absences, and academic grades.

**Source:** [UCI Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student%2Bperformance)
